# Note on the pre-event local prototype

Before the hackathon the team built a small local backend prototype (demo apps, a concurrency test controller, an invariant filter, an LLM invariant-proposal call, and a repair-validation spike for one wallet scenario). The organisers gave written permission to build a local prototype before the event, on the condition that nothing was committed before the hackathon started. Nothing was committed before the start.

Files in `controller/` and `orchestrator/` were adapted from that prototype. A separate repository named `prototype-gH` holds the prototype as reference; it was first committed on 26 Oct 2026 at 11:20 IST, after the window opened. Everything else (dashboard, API, apps, CLI, validation and repair work, evaluation) is written during the 24-hour window.

The prototype was only run against demo apps we wrote ourselves. Results from it are background, not results of this project.
